# Base de conocimiento local

Estos archivos contienen conocimiento controlado que el bot puede recuperar antes de consultar al modelo.

- `glosario-masonico.json`: definiciones y términos aprobados.
- `faq-base.json`: respuestas base verificadas.

No agregues borradores, afirmaciones sin fuente ni versiones contradictorias. Incrementa el campo `version` cuando hagas cambios relevantes.
